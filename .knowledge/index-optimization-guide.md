## 📋 如何添加Logo

### ⚠️ 重要说明
你的Logo文件是 `.ai` 格式（Adobe Illustrator），无法直接在网页中使用。

### 解决方案：转换为PNG

#### 方法1：使用Adobe Illustrator（推荐）
1. 用 AI 打开 `LCP-logo.ai` 或 `中信保诚 LOGO.ai`
2. 文件 → 导出 → 导出为...
3. 格式选择：PNG
4. 设置：
   - 分辨率：300 DPI（高清）
   - 背景：透明
   - 尺寸：建议宽度 800-1000px
5. 保存为 `logo.png` 或 `company-logo.png`
6. 将文件复制到 `src/static/` 目录

#### 方法2：使用在线转换工具
- 访问 [CloudConvert](https://cloudconvert.com/ai-to-png)
- 上传 `.ai` 文件
- 转换为 PNG 格式
- 下载并放到 `src/static/`

#### 方法3：使用其他设计软件
- Photoshop：打开 AI 文件 → 导出 PNG
- Figma：导入 AI → 导出 PNG
- Canva：上传 AI → 下载 PNG

### 添加Logo到页面

转换完成后，修改 `index.vue` 的 Logo 部分：

```vue
<!-- 找到这行 -->
<!-- <image src="/static/logo.png" class="logo-img" mode="aspectFit"></image> -->

<!-- 去掉注释，改成你的Logo文件名 -->
<image src="/static/company-logo.png" class="logo-img" mode="aspectFit"></image>
```

### 调整Logo大小

如果Logo太大或太小，修改样式：

```scss
.logo-img {
  width: 280rpx;    // 调整宽度
  height: 100rpx;   // 调整高度
  opacity: 0.9;     // 调整透明度 (0-1)
}
```

建议尺寸：
- **横版Logo**：width: 280-400rpx, height: 80-120rpx
- **方形Logo**：width: 120rpx, height: 120rpx
- **竖版Logo**：width: 100rpx, height: 150rpx

### 九紫离火漂浮效果

```scss
// 每个字都有不同的延迟

紫 - 0.2s 延迟
离 - 0.4s 延迟

0%   - 原位置，70%透明度

50%  - 向上8rpx，缩放1.02倍，80%透明度
75%  - 向上20rpx，缩放1.08倍，95%透明度
100% - 回到原位置
```

## 🐛 故障排查

**检查**：
- 确认引入了 `@/styles/global.css`（Animate.css）
- 检查浏览器控制台是否有错误
- 尝试刷新页面

### 问题3：按钮样式不对
**检查**：
- 确认 Tailwind CSS 已正确配置
- 检查 `postcss.config.js` 是否包含 tailwindcss
- 重启开发服务器

### 问题4：Logo显示异常
**检查**：
- 确认 Logo 已转换为 PNG 格式
- 检查文件路径是否正确
- 调整 logo-img 的 width 和 height
