# 首页性能优化说明

## 🎯 已解决的问题

### 1.  标题闪烁问题（2025 → 2026）
**原因：** `manifest.json` 中的应用名称是"来自2025的好消息算命"

**解决方案：**
```json
// src/manifest.json
"name" : "来自2026的好消息算命"
```

---

### 2.  页面加载慢问题
**原因：** 省市数据在 `onLoad` 生命周期中同步加载，阻塞了页面渲染

**解决方案：** 异步预加载策略
```javascript
onLoad(op) {
  // 使用 setTimeout 延迟加载，确保页面先渲染
  setTimeout(() => {
    this.preloadAreaData();
  }, 100);
}
```

**优化效果：**
- ⚡ 页面立即渲染，用户无需等待
- 📦 数据在后台静默加载
- 💾 首次加载后会缓存，第二次访问秒开

## 🔍 如何诊断慢的原因

### 1. 查看控制台日志

访问 https://yixue.linqingkeji.com/ 后，按 `F12` 打开控制台，查看日志：

#### 如果看到：
```
 [性能] 页面渲染完成 { 耗时: '3000ms', ... }
⚠️ [性能警告] 页面加载超过2秒，耗时: 3000ms
```
**原因：** 前端资源加载慢
- 检查静态资源大小（图片、字体、JS文件）
- 检查 CDN 是否正常
- 检查网络带宽

#### 如果看到：
```
⚠️ [API警告] 省份数据请求耗时过长: 2500ms
💡 [建议] 检查服务器性能或网络状况
```
**原因：** 后端 API 响应慢
- 检查服务器 CPU/内存使用率
- 检查数据库查询性能
- 检查 Docker 容器资源限制
- 检查网络延迟

## 🐳 Docker 资源检查

### 查看容器资源使用
```bash
# 查看容器资源占用
docker stats

# 查看容器详细信息
docker inspect <容器名>

# 查看容器日志
docker logs <容器名>
```

### 常见问题

#### 1. CPU 限制过低
```yaml
# docker-compose.yml
services:
  app:
    cpus: '0.5'  # 太低，建议至少 1.0
```

#### 2. 内存限制过低
```yaml
services:
  app:
    mem_limit: 128m  # 太低，建议至少 512m
```

#### 3. 数据库连接池不足
```php
// 检查数据库连接配置
'database' => [
    'pool_min' => 1,    // 最小连接数
    'pool_max' => 10,   // 最大连接数（可能不足）
]
```
